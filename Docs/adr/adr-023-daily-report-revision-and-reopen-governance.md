# ADR-023 — Daily Report Revision and Reopen Governance

**Status:** Accepted  
**Date:** 2026-10-01  
**Decision scope:** CMX Sekolah Rakyat EOS Operations Platform MVP

## Context
Submitted reports must remain trustworthy but controlled revision is needed.

## Decision
Supervisor within site scope and Super Admin may reopen a submitted report within seven calendar days. Reason is mandatory. Reopen is audited; resubmission increments revision while report number remains immutable.

## Consequences
Submitted content is immutable except through explicit reopen.
