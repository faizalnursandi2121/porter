## What This Is

**PORTER (Portal Operasional Terpadu)** — internal web app for Comtronics to monitor daily field operations of **Engineer On Site (EOS)** technicians placed at **Sekolah Rakyat** school sites across Indonesia (~200 sites, 1 EOS per site, timezones WIB/WITA/WIT).

One full-stack app: **Laravel 13 + Inertia v3 + React 19 + Tailwind 4 + shadcn/ui** (existing starter kit), **PostgreSQL**, deploy **GitHub → Dokploy**. PWA-installable. No REST API layer, no separate SPA backend.

The product exists to answer: *was the EOS present at the school, what is the device/network condition, what inventory is at the site* — with auditable evidence.

## The Four Modules

1. **Attendance proof** — check-in & check-out, each with one selfie + GPS, server timestamp (UTC) as source of truth. Proof only — no lateness/payroll logic (that belongs to the EOS vendor's system).
2. **Daily Report** — 5-section structured checklist (Info Umum, Router & Firewall, Access Point, Infrastruktur & Lingkungan, Konektivitas Dual-Link) with mandatory photo evidence, versioned templates, server-side draft, official report number `CMX.WR.YYYYMM.SEQUENCE`.
3. **Inventory per site** — EOS records goods arriving from central warehouse (name, category, qty, ≥1 photo); asset status `dipakai/cadangan/rusak/dikembalikan/hilang` (reason required for rusak/hilang); consumable stock ledger; stock can never go negative; inventory belongs to the SITE, never the EOS.
4. **KPI Dashboard** — aggregated analytics (attendance %, report completeness, network health, environment, anomalies, inventory) filterable by period/site/EOS, exportable to Excel/PDF. Plus append-only audit log viewer for Administrator.

## Roles (4, single role per user)

| Role | Scope |
|---|---|
| **EOS** | Mobile-first. Check-in/out, fill daily report, record incoming inventory, view own history. |
| **Supervisi** | ALL sites. Creates users (incl. EOS) + assigns/moves/ends placements. Reviews reports (reopen), corrects inventory, sees all KPIs. |
| **HR** | Attendance data + selfie (workforce purposes), EOS profiles & placements. NOT report/inventory evidence. |
| **Administrator** | Everything Supervisi has, plus: report templates, master data, audit log, export. |

## Locked Product Decisions (owner-confirmed — do not relitigate)

No stock thresholds (dashboard recap only) · EOS self-revision same-day only + Supervisi reopen anytime with reason · report gate before clock-out · separate selfie per event · same-date rule · no cut-off times · unlimited retention (purge = later phase) · PDF export simple header, no signatures · manual warehouse entry (Excel import = later phase) · lost = asset status + mandatory reason · photo access via audited app endpoint · snapshot + stable-field KPI across template versions · server-side drafts · GitHub→Dokploy deploy, no staging env.

## Out of Scope (MVP — do not build)
